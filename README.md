# Adversarial Wireless Communications Resources

This repository summarizes publicly available datasets, simulators, frameworks, and toolkits used in adversarial machine learning research for wireless communications.

| Category | Resource | Main Use | Official Link |
|---|---|---|---|
| Dataset | RadioML | AMC benchmarks using synthetic I/Q samples | https://www.deepsig.ai/datasets |
| Dataset | COST 2100 | MIMO channel modeling | https://www.cost2100.org/ |
| Dataset / Framework | DeepMIMO | mmWave and massive MIMO channel datasets | https://www.deepmimo.net/ |
| Dataset | ElectroSense | Large-scale radio spectrum sensing measurements | https://electrosense.org/ |
| Geospatial Data | OpenStreetMap | Site-specific environment geometry | https://www.openstreetmap.org/ |
| Mobility Simulator | SUMO | Realistic traffic and mobility simulation | https://eclipse.dev/sumo/ |
| AML Toolkit | CleverHans | Reference adversarial attack implementations | https://github.com/cleverhans-lab/cleverhans |
| AML Toolkit | ART | Attacks, defenses, and robustness evaluation | https://adversarial-robustness-toolbox.org/ |
| AML Toolkit | Foolbox | Benchmarking adversarial robustness | https://github.com/bethgelab/foolbox |
| Benchmark | RobustBench | Standardized robustness evaluation | https://robustbench.github.io/ |
| Wireless Toolkit | GNU Radio | Software-defined radio experimentation | https://www.gnuradio.org/ |
| Wireless Simulator | Sionna | Differentiable communication-system simulation | https://nvlabs.github.io/sionna/ |
| Wireless Emulator | Colosseum | Large-scale wireless network emulation | https://www.northeastern.edu/colosseum/ |
| O-RAN Framework | OpenRAN Gym | AI-driven experimentation for O-RAN systems | https://openrangym.com/ |
| Network Simulator | ns-3 | Wireless protocol-stack simulation | https://www.nsnam.org/ |
| O-RAN Simulator | ns-O-RAN | O-RAN extension for ns-3 and 5G simulations | https://github.com/wineslab/ns-o-ran-ns3-mmwave |
| O-RAN Platform | O-RAN SC | Open-source O-RAN software ecosystem | https://o-ran-sc.org/ |
| Wireless Testbed | ARA / Arena | Real-world wireless experimentation platform | https://arawireless.org/ |
| RFML Framework | HermesPy | Wireless-system and RFML simulation framework | https://hermespy.org/ |
| RFML Toolkit | RFML | Adversarial RFML experimentation toolkit | https://github.com/brysef/rfml |
| SDR / Wireless Stack | srsRAN | Open-source 4G/5G software radio stack | https://www.srsran.com/ |
| AI-Native Wireless Platform | NVIDIA Aerial | GPU-accelerated AI-native wireless research | https://developer.nvidia.com/aerial |
| Wireless Research Platform | AERPAW | AI-native aerial and wireless experimentation | https://aerpaw.org/ |
